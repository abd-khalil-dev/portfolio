# Abdullah Khalil · Portfolio

Personal portfolio of **Abdullah Khalil**, DevOps & AWS Cloud Engineer (Islamabad, Pakistan).

A static, dependency-free site: one `index.html` (HTML, CSS, vanilla JS), deployed on **Vercel** with automatic deploys on every push to `main`.

## Files
| File | Purpose |
|---|---|
| `index.html` | The whole site |
| `abdullah.webp` | Hero photo (transparent background) |
| `og.jpg` | Link preview image for LinkedIn / WhatsApp |
| `favicon.svg` | Browser tab icon |
| `vercel.json` | Clean URLs, security headers, asset caching |

## Deploy
1. Push this repo to GitHub.
2. On [vercel.com](https://vercel.com) choose **Add New → Project**, import the repo, keep Framework Preset = **Other**, and click **Deploy**.
3. Every push to `main` redeploys automatically.

## Editing
- WhatsApp: search for `To add WhatsApp` in `index.html` and uncomment the lines.
- After the first deploy, add the live URL to the `og:url` meta tag if you want full link previews.
